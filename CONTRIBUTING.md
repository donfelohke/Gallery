# Contributing to Gallery

Gallery is a curated asset repository, not a general-purpose upload dump.

## Before proposing an asset

1. Confirm that you created it or have documented permission to redistribute it.
2. Record the creator, source, rights/licence and any attribution requirements.
3. Check for private customer information and confirm appropriate consent for identifiable people where required.
4. Confirm the asset is the best available approved version; avoid duplicates, watermarks and obsolete drafts.
5. Add a complete entry to `ASSET-MANIFEST.md`.
6. Explain the intended brand context and use in the pull request.

## Review status

Use these states consistently:

- **Proposed** — submitted, not yet reviewed.
- **Under review** — provenance, quality or intended use is being checked.
- **Approved** — reviewed for the stated use.
- **Rejected** — not accepted.
- **Retired** — no longer recommended for new use.

Submission is not approval. Approval for one use does not automatically authorise every other use.

## Website rule

Do not add images to the NAKEBUSEN website repository or embed Gallery assets in website HTML. The website may link to the Gallery repository as a separate destination.

## Changes

Use a descriptive branch and pull request. Keep each change focused, explain its purpose, and include the manifest update alongside any asset addition or replacement.
