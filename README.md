# Gallery — Curated Assets · Supporting Repository

**Maintainer:** Feloh Warena · [@donfelohke](https://github.com/donfelohke)  
**Status:** Initialized · asset inventory and formal approvals pending

Gallery is a supporting asset-governance repository for visual and creative materials associated with NAKEBUSEN, WARENA, IKAI, GENJE and FELOH. It is not a fifth practice domain. Assets remain proposed until their source, rights, consent, intended use and approval are recorded.

**Public-facing description:** Gallery is a rights-aware archive for selected visual and creative work. It is not a live website gallery and it is not an unreviewed upload dump. The public website links here as text; it does not embed these assets.

The public website may **link** to this repository. It must **not** embed Gallery images or depend on image files to render. Website policy remains text-first.

## Curation rules

Before adding an asset, record the following where applicable:

- Title and intended use  
- Creator / source  
- Copyright holder · licence or written permission  
- Approval status and date  
- Brand domain and usage restrictions  
- Consent for people depicted  

Do not infer permission from “publicly available.” Do not add private customer material, unlicensed work, drafts presented as approved, or stock material presented as real client results.

Maintain a living inventory in `ASSET-MANIFEST.md` when assets exist. Do not create empty category folders that imply a complete collection.

## Licensing

The repository includes a GNU General Public License, version 3 (`LICENSE`). That licence governs material to which it applies; it must not be assumed to grant rights in separately copyrighted or third-party creative assets. For each curated asset, document the applicable licence or written permission, attribution requirements, and permitted uses in `ASSET-MANIFEST.md`. If an asset's rights are unknown, do not publish it as approved.

## Release rule

An asset is not approved until its original binary is committed, visual quality and mobile legibility are checked, source and rights are recorded, consent is confirmed where relevant, intended use and restrictions are clear, and a human review is recorded.
