# Gallery asset review record template

**Status:** TEMPLATE ONLY. No asset is approved by this document.

Use one record per original asset. Do not approve a batch solely because files share a folder, campaign, creator or upload date.

## Asset identity and integrity

| Field | Record |
|---|---|
| Asset ID | Stable unique ID |
| Filename | Exact committed path |
| SHA-256 | Hash of the reviewed original |
| Media type / dimensions | Observed format, dimensions, duration where relevant |
| Creator | Credited creator or unknown |
| Source | Original capture / creator delivery / archive / external source |
| Capture or creation date | Exact date or unknown |
| Intake date | Date received |
| Context | What the asset depicts or documents, without unsupported inference |

## Rights and consent

| Field | Record |
|---|---|
| Rights holder | Person or entity, or unresolved |
| Rights basis | Written licence / assignment / public-domain basis / other / unknown |
| Evidence location | Exact permission, licence or source record |
| Attribution | Required credit wording |
| Identifiable people | Yes / no / uncertain |
| Consent evidence | Record reference; not merely “publicly posted” |
| Consent scope | Channels, purpose, territory, duration and editing permissions |
| Restrictions | Cropping, editing, commercial use, sublicensing, sensitive context |
| Withdrawal route | Contact and handling process where applicable |

Do not infer consent from possession, a public social post, a photographer's permission alone, or a campaign brief. Where rights or consent are uncertain, retain the asset as not approved.

## Intended use and human decision

| Field | Record |
|---|---|
| Intended brand / project | NAKEBUSEN / WARENA / IKAI / GENJE / FELOH / research |
| Exact proposed use | Specific page, print item, event, archive or campaign |
| Audience and distribution | Private / internal / public / commercial |
| Context review | Risks of misrepresentation, cultural flattening or misleading crop |
| Decision | INTAKE / NEEDS-SOURCE / RIGHTS-UNCLEAR / CONSENT-PENDING / REVIEW / APPROVED / REJECTED / SUPERSEDED |
| Reviewer | Named human reviewer |
| Decision date | Date |
| Rationale | Short evidence-based explanation |
| Re-review trigger | Changed use, licence, consent, context or asset edit |

Only APPROVED assets may be used for the specific recorded intended use. Approval is not transferable to a different campaign, channel or commercial purpose without review.

## Verification procedure

1. Compare the committed original with the intake record; compute and record its SHA-256.
2. Open the original file and confirm it is readable and is the file actually reviewed.
3. Verify source and rights evidence independently.
4. Confirm consent where people are identifiable or otherwise required.
5. Review context, crop, accessibility and intended-use fit.
6. Record a human decision and its date. Keep rejected and superseded records auditable.
7. Recheck the decision if the asset or its intended use changes.

## Publication boundary

The NAKEBUSEN public website remains text-first and may link to Gallery; it must not embed Gallery images or depend on them to render. Repository visibility is not permission. Repository code/text licensing does not automatically license separately copyrighted images, audio or other assets.

**No rights evidence = no approval. No consent where required = no publication.**
