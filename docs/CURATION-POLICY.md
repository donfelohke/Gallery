# Curation policy

## Approval states

| State | Meaning |
|-------|--------|
| PROPOSED | Uploaded or listed; not cleared |
| RIGHTS-CLEARED | Licence/consent recorded |
| BRAND-APPROVED | OK for named uses (list them) |
| WEB-APPROVED | Explicitly allowed on public site (rare; site is text-first) |
| REJECTED | Do not use |
| RETIRED | Was approved; withdrawn |

## Required metadata (minimum)

- Filename / ID  
- Creator  
- Date  
- Source  
- Licence or permission note  
- Subjects / consent if people are identifiable  
- Allowed uses  
- Approval state  

## Prohibitions

- Stock or AI imagery presented as client work  
- Client faces without consent  
- Secrets or IDs in EXIF left unreviewed
